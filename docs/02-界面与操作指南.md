# 02 · 界面与操作指南

---

## 1. 入口一览

| 入口 | 位置 | 用途 |
| --- | --- | --- |
| **侧边栏 DepScan** | 活动栏（左侧图标列） | 「索引状态」+「依赖」两个常驻视图 |
| **索引状态视图** | 侧边栏 → DepScan → 索引状态 | 进度、统计、精度、警告；标题栏有 ⟳ 重建 / ⏹ 取消 / 🗑 清缓存 |
| **依赖视图** | 侧边栏 → DepScan → 依赖 | 当前文件的「被谁依赖 / 依赖了谁」树，可逐层展开 |
| **编辑器右键菜单** | `.cpp/.h` 文件内右键 | 查看依赖图 / 查看当前符号的依赖图 |
| **资源管理器右键菜单** | 文件树上的文件右键 | 查看依赖图 |
| **状态栏** | 左下角 | 实时进度与规模；点击打开索引详情 |
| **命令面板** | `Ctrl+Shift+P` → 输入 `DepScan` | 全部命令 |

### 命令清单

| 命令 | 说明 |
| --- | --- |
| `DepScan: 重建索引（全量）` | 忽略缓存，重新扫描全部文件 |
| `DepScan: 取消索引` | 中断正在进行的索引 |
| `DepScan: 清理索引缓存` | 删除缓存目录（下次索引会变慢但更干净） |
| `DepScan: 查看索引状态` | 弹出统计、精度来源、引擎路径、缓存路径；可直接触发重建 |
| `DepScan: 查看依赖图` | 以当前文件（或选中的文件）为焦点打开依赖图 |
| `DepScan: 查看当前符号的依赖图` | 以光标所在函数/类为焦点 |
| `DepScan: 导出依赖数据（JSON）` | 导出当前焦点子图（含 stats 元信息） |
| `DepScan: 导出依赖图（PNG / SVG）` | 先打开依赖图，再在图中工具栏导出 |
| `DepScan: 如何生成 compile_commands.json？` | 打开生成指引 |
| `DepScan: 打开 DepScan 使用文档` | 打开 docs/01 |
| `DepScan: 刷新依赖视图` | 刷新侧边栏树（缓存失效） |

## 2. 依赖图（Graph 视图）

### 画布操作

| 操作 | 效果 |
| --- | --- |
| 拖动节点 | 钉住该节点并移动（松手后解除钉住） |
| 滚轮 | 以光标为锚点缩放 |
| 拖动空白处 | 平移画布 |
| 单击节点 | 选中 + 高亮邻居；开启「点击跳转源码」时同时跳到定义位置 |
| 双击节点 | **展开下一层**（把该节点的邻居合并进当前图） |
| 悬停节点 | 右侧详情面板显示类型 / 文件:行 / 精度 / 出入度 / 签名 |
| 单击空白 | 取消选中，恢复全图色彩 |

### 工具栏

| 控件 | 说明 |
| --- | --- |
| **层级 k** | 以焦点为中心的 BFS 层数（1–6）。k 越大越全，也越慢 |
| **方向** | `双向` / `被谁依赖`（上游）/ `依赖了谁`（下游） |
| **显示项目外符号** | 打开后能看到未解析到定义的符号（标准库、第三方库）。默认关闭以避免噪声 |
| **按目录聚类** | 把同目录的节点折叠成目录节点（LOD 第 1 层），用于全局鸟瞰 |
| **点击跳转源码** | 关闭后单击只做选中，不跳转 |
| **⤢ 适应窗口** | 重新计算缩放，让整张图铺满画布 |
| **⟳ 刷新** | 按当前 k / 方向重新拉取子图 |
| **▦ 全局架构视图** | 按目录聚合的整项目架构图 |
| **PNG / SVG / JSON / DOT / MMD** | 导出 |

### 边的读法

- **颜色**：蓝=包含，绿=调用，橙=继承，紫=类型依赖，灰=符号引用，青=链接
- **实线** = 精确（来自 compile_commands 的真实路径 / CMake 元数据）
- **虚线** = 近似（结构级推断）
- 箭头方向：`A → B` 表示 **A 依赖 B**（A include 了 B / A 调用了 B / A 继承了 B）

### 图例与详情

右侧面板上半是**详情**（悬停/选中时刷新），下半是**图例**（只显示当前图中真实出现的类型，不是固定列表）。

## 3. 树视图（Tree 视图）

以当前焦点为根：

```
▾ 被谁依赖
  ├─ <includes> main.cpp
  ├─ <calls>    run()
  └─ ...
▾ 依赖了谁
  ├─ <includes> core/base.h
  └─ <calls>    compute()
```

- 每行显示 `<边类型>` 徽标 + 节点名
- 单击行：选中 + 跳转源码
- 双击行：在图中展开该节点
- 搜索框输入关键字时，树会自动只保留命中的分支（含其祖先）

---

## 4. 表格视图（Table 视图）

| 列 | 说明 |
| --- | --- |
| 节点 | 名称（前面小圆点表示类型） |
| 类型 | 文件 / 函数 / 类 / 枚举 / 变量 / 宏 / 构建目标 |
| 出依赖 | 该节点依赖了多少东西（out-degree） |
| 入依赖 | 有多少东西依赖它（in-degree） |
| 文件 | 定义位置 `路径:行号` |
| 精度 | 精确 / 近似 |

默认按「出依赖 + 入依赖」降序 —— **排在最上面的就是整个子图的枢纽节点**，通常是你最该先读的东西。

搜索框同时过滤树和表格，并会把图里的第一个命中项选中。

---

## 5. 三视图联动

在任一视图点选一个节点：

- 图中该节点加白色描边，邻居正常着色，非邻居淡化到 18% 透明度
- 树里对应行高亮，并自动展开到该节点所在分支
- 表格里对应行高亮

这是「从架构看到具体代码」的关键：先在图里看形状，再在表格里找枢纽，最后跳到源码。

## 6. 导出

| 格式 | 用途 | 体积 |
| --- | --- | --- |
| **PNG** | 贴进 issue / 文档 / PPT | 中（2 倍分辨率，导出整图而非当前视口） |
| **SVG** | 矢量图，可无损缩放、可二次编辑 | 小 |
| **JSON** | 二次处理（脚本、图算法、导入到其他工具） | 中 |
| **DOT** | Graphviz，适合出版级排版 | 小 |
| **Mermaid** | 直接粘进 Markdown / 文档站 | 小 |

JSON 结构：

```json
{
  "generator": "DepScan",
  "version": "0.1.0",
  "root": "/path/to/project",
  "stats": { "fileCount": 15, "edgeCount": 76, "precision": "approx", "...": "..." },
  "graph": {
    "nodes": [{ "id": "file:src/main.cpp", "kind": "file", "name": "src/main.cpp", "precision": "exact", "...": "..." }],
    "edges": [{ "from": "file:src/main.cpp", "to": "file:src/util/logger.h", "kind": "includes", "line": 3 }]
  }
}
```

节点 `id` 命名规则（稳定、可脚本化）：

```
file:<相对路径>     func:<限定名>      class:<限定名>
enum:<限定名>       var:<限定名>       macro:<宏名>
target:<target 名>  ext:<类型>:<名字>   ← 项目外/未解析符号
```

## 7. 索引、缓存与增量

### 索引流程

```
打开工作区
   ↓ 自动（depscan.index.onStartup）
发现 compile_commands.json → 决定精度
   ↓
文件发现（files.include / exclude 过滤）
   ↓
多线程并行结构解析（threads = CPU 核心数）
   ↓
符号表 → include 解析 → 引用消解 → CMake 链接模型 → 图构建
   ↓
写磁盘缓存 → 通知 UI
```

### 增量更新（保存文件后自动发生）

```
文件保存 / 新建 / 删除
   ↓ 防抖 400ms
只重解析变化的文件
   ↓
重建图（受影响子图合并回主图）
   ↓
写缓存 → 通知依赖视图与依赖图刷新
```

若正在全量索引，保存事件会被忽略（避免互相干扰）；全量结束后再保存一次即可。

### 缓存

- 默认位置：`<工作区>/.vscode/depscan-cache/index-v1.txt`
- 失效判定：**文件 mtime + size**（变化才重解析，其余直接复用）
- 缓存头部记录项目根路径 —— 换项目自动失效，不会串味
- 想强制冷启动：`DepScan: 清理索引缓存` 或 `DepScan: 重建索引（全量）`

## 8. 配置在哪里改

- 图形界面：`Ctrl+,` → 搜索 `depscan`
- 工作区级（推荐，可随项目提交）：

```jsonc
// .vscode/settings.json
{
  "depscan.deps.calls": true,
  "depscan.index.parallelism": 8,
  "depscan.files.exclude": ["**/build/**", "**/third_party/**", "**/_deps/**"],
  "depscan.graph.defaultDepth": 2,
  "depscan.ui.language": "zh"
}
```

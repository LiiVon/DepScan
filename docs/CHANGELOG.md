# 更新日志

本项目遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

---

## 0.1.0 — 首个可用版本

### 新增

**分析引擎（C++20 / CMake，独立进程，零外部依赖）**

- 五类依赖识别：`includes` / `calls` / `inherits`+`uses` / `refs` / `links`
- 内置 C/C++ 词法与结构解析器：注释与字符串剥离、原始字符串、跨行续行、`operator` 重载、命名空间与类作用域限定
- `#include` 宏展开（`#define X "a.h"` → `#include X`）与三级精度标注（精确 / 部分精确 / 近似）
- `compile_commands.json` 自动发现与解析：提取 `-I/-isystem/-D`，逐文件还原真实编译参数
- 符号表构建与引用消解（同名候选优先同文件，>3 候选聚合为未解析节点）
- CMake 构建模型解析：`add_executable` / `add_library` / `target_link_libraries` → 目标与链接依赖
- 多线程并行解析（任务队列 + 原子分配），文件级结果复用
- 服务端 k 层 BFS 子图裁剪，服务端按目录聚合的全局架构视图
- 磁盘缓存（文件级 `mtime + size` + 全量**配置指纹**：根目录 / 编译数据库路径与 mtime / include 路径 / 宏），编译数据库变化即整份作废
- 导出：JSON / DOT / Mermaid
- 单文件增量更新与「受影响文件」查询

**VS Code 插件（TypeScript）**

- 命令：重建索引 / 取消索引 / 清理缓存 / 查看索引状态 / **为什么是近似？（精度诊断）** / 查看依赖图 / 查看当前符号的依赖图 / 导出 / 生成指引 / 打开文档 / 刷新依赖视图
- 侧边栏：**操作视图**（常用命令一次点击，含语言子菜单与当前精度）、索引状态视图（进度、统计、三级精度、警告）、依赖视图（双向依赖树，逐层展开）
- 状态栏：实时索引进度、规模与当前精度
- 编辑器与资源管理器右键菜单
- 保存事件触发的增量重建（400ms 防抖）+ 文件增删监听
- **监听 `compile_commands.json` 的增删改**，防抖 800ms 后自动全量重新索引（先索引、后生成编译数据库也能自愈）
- 中英双语 UI（默认中文，可 `auto` 跟随 VS Code；侧边栏与依赖图工具栏均可切换）
- 完整配置项（见 `docs/05-性能与配置参考.md`）
- 引擎定位：配置 → 内置 `engines/<platform>-<arch>/` → 开发态构建目录

**Webview 可视化（无第三方前端依赖）**

- Canvas 力导向图：拖动节点、滚轮缩放、平移、单击跳转源码、双击展开下一层
- 三视图联动：依赖图 / 层级树 / 表格（选中同步高亮与导航）
- 方向开关（双向 / 上游 / 下游）、层级 k 调节、按目录聚类、外部符号显示开关
- LOD：节点数 > 260 改用网格布局，> 400 自动按目录聚类；标签随缩放等级显隐
- 导出 PNG（离屏 2 倍渲染整图）/ SVG（矢量）/ JSON / DOT / Mermaid
- 节点与边按类型着色，实线 = 精确、虚线 = 近似

**工程与质量**

- `samples/demo`：15 文件示例项目，含循环包含与分层违规
- 引擎自测 29 项（词法 / 预处理 / 五类依赖 / 图 / 缓存格式 / glob）
- JSON-RPC 协议冒烟测试 24 项（真实子进程驱动全部方法，含 compile_commands 精确路径）
- Webview 离线自检：脚本语法 + DOM id 对齐 + 内嵌 JSON 解析 + CSP 校验
- 压力测试脚本：10 万行与百万行两档合成工程，输出可复现报告
- 三平台引擎分发方案与打包脚本

### 已知限制

- 无 `compile_commands.json` 时，调用 / 继承 / 类型依赖为结构级近似，重载决议与模板实例化不保证正确
- 链接依赖目前只解析 CMake；Makefile / Bazel / qmake 需借助 `compile_commands.json`
- libclang 精确语义分析路径已预留（`-DDEPS_USE_LIBCLANG=ON`），本版本默认关闭
- 峰值内存未插桩
- 磁盘缓存为文本格式，超大型项目缓存文件可能较大
